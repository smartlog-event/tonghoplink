Cần mã khoá GitHub, chỉ một lần trên máy này

Các nút được lưu vào GitHub để mọi máy và mọi điện thoại đều thấy giống nhau. GitHub bắt buộc phải có mã khoá mới cho ghi. Dán một lần, trình duyệt nhớ luôn, lần sau không hỏi lại.

  1. Bấm Mở trang tạo mã khoá bên dưới (mở tab mới, đã chọn sẵn quyền cần thiết).
  2. Kéo xuống cuối, bấm Generate token.
  3. Copy chuỗi ký tự vừa hiện ra — GitHub chỉ hiện đúng một lần.
  4. Quay lại đây, dán vào ô dưới.
